# PlayerPose（1.7.10 / MPM 1.7.10b 必須）

プレイヤーに6種類の静止ポーズを取らせるmodです。`/pose` で円形の選択画面が開きます。

## 1. 開発環境の作り方

1. GitHub の **GTNewHorizons/ExampleMod1.7.10** の Releases から「starter」パッケージをダウンロードし、空のフォルダに展開します。
2. テンプレートに入っているサンプルの Java ファイル（`src/main/java` の中身）と `src/main/resources` の中身を削除します。
3. このフォルダの `src/` をテンプレートの `src/` に上書きコピーします。
4. `libs/` フォルダを作り、`MorePlayerModels_1.7.10b.jar` を入れます。
5. このフォルダの `dependencies.gradle` で、テンプレートの同名ファイルを置き換えます。
6. `gradle.properties` を次のように変更します（それ以外はテンプレートのまま）。
   - `modName = PlayerPose`
   - `modId = playerpose`
   - `modGroup = playerpose`
7. IntelliJ IDEA でフォルダを開き、Gradle の読み込みが終わったら `runClient` で起動します。
8. 完成版は `gradlew build` で作ります。`build/libs/` にできる jar（`-dev` や `-sources` が付いていないもの）を、**サーバーと全クライアントの両方**の mods フォルダに入れます。

> 手順5の `rfg.deobf(files(...))` でエラーが出た場合は、エラーの文面を教えてください。書き方を直します。

## 2. 使い方

| コマンド | 動作 |
|---|---|
| `/pose` | 選択画面を開く（クリック or 数字キー1〜6で決定、中央クリック or 0キーで解除、Escで閉じる） |
| `/pose 1`〜`/pose 6` | そのポーズを取る |
| `/pose off` | ポーズ解除 |
| `/pose reload` | 設定ファイルを読み直す（角度調整用） |

ポーズ：1 左扉抑え / 2 右扉抑え / 3 左側面監視 / 4 右側面監視 / 5 右手上げ / 6 左手上げ
（2・4・6 は 1・3・5 の左右反転を自動で作っています）

解除される条件：移動（乗車中を除く）、スニーク開始、乗車・降車・乗り換え、MPMのモーション開始、就寝、死亡、リスポーン、ディメンション移動、ログアウト。
スニーク中・就寝中・MPMのモーション中はポーズを取れません。

## 3. 実機での角度調整

`config/playerpose.cfg` に基本ポーズ（1・3・5）の角度が書かれています。値を書き換えて `/pose reload` を打つと、再起動せずに反映されます。

- 各部位は `"X,Y,Z"`（度）
  - X：マイナスで腕・脚が前へ
  - Z：右腕・右脚はプラス、左腕・左脚はマイナスで外側へ
- `bodyLean`：上半身を腰から傾ける角度（プラスで左へ）
- `ridingYOffset`：乗車中にポーズを取ったとき、見た目を上げる量（ブロック）

設定ファイルの角度は **その人の画面の描画にだけ** 効きます。調整が決まったら、値を `PoseRegistry.java` の初期値に書き写して配布してください。

## 4. 確認してほしいこと（実機テスト）

- [ ] 三人称（F5）で6ポーズが正しい形・正しい左右になるか（左右が逆なら Z の符号を逆にする）
- [ ] ポーズ中も一人称の腕が普通の形のままか
- [ ] 防具・手持ちアイテム・MPMの帽子レイヤーがポーズに付いてくるか
- [ ] 3・4（上半身を傾ける）で頭と腕が胴から外れないか
- [ ] 歩く・ジャンプ・スニーク・乗車・MPMの /sit で解除されるか
- [ ] RTM の車両に乗ったままポーズを取れるか、脚が床を貫通しないか（`ridingYOffset` で調整）
- [ ] マルチで、他の人のポーズが見えるか（離れた所から近づいた場合も2秒以内に見えるか）
- [ ] OptiFine（シェーダー含む）で表示が崩れないか
- [ ] MPMで体型を変えている人・特殊な脚（ナーガ脚など）の人の見え方
