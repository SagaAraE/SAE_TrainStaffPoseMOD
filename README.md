# SAE TrainStaffPose（1.7.10 / More Player Models 1.7.10b 必須）

列車乗務員向けに、プレイヤーに9種類の静止ポーズを取らせるmodです。サーバーと全クライアントの両方に入れてください。
配布用の説明書は `docs/README.txt`（ビルド時にバージョンを入れてjarと一緒にzipへ同梱）。

## 操作

| 操作 | 動作 |
|---|---|
| **Home** キー / `/pose` | 選択画面（円形メニュー）を開く |
| **↑** キー | 次のポーズへ（円形メニューを時計回り） |
| **↓** キー | 前のポーズへ（円形メニューを反時計回り） |
| 選択画面 | クリック or 数字キー1〜9で決定。下の「解除」・中央・0キーで解除。Esc / Home で閉じる |
| 選択画面の「調整」 | 乗車中の位置・視点の調整画面を開く |
| `/pose 1`〜`/pose 9` | その番号のポーズを取る |
| `/pose off` | 解除 |
| `/pose reload` | 設定ファイルを読み直す |

キーは「設定 → 操作設定」で変更可。↑↓で切り替えると画面上部にポーズ名を表示。

## ポーズ番号と円形メニューの並び

番号は円形メニューを下（解除）から時計回りに一周する順番（↑キーで進む順番と同じ）。

| 位置 | 左側 | 右側 |
|---|---|---|
| 上 | 5 起立 | ← |
| | 4 左側面監視 | 6 右側面監視 |
| | 3 左側面監視（手上げ） | 7 右側面監視（手上げ） |
| | 2 扉抑え（左手上げ） | 8 扉抑え（右手上げ） |
| | 1 左手上げ | 9 右手上げ |
| 下 | 0 解除 | ← |

- 1・9 手上げ：下ろした腕と脚は歩くと振れる
- 5 起立：頭は視線に追従、歩くと腕と脚が振れる
- 3・7 側面監視（手上げ）：側面監視と同じく上半身を傾け、傾いた側の手を上げる
- 手上げ（1・9）と側面監視（手上げ）（3・7）は、手持ちアイテムを上げた手に持ち、絵を左右反転して外側へ倒して描く
- 側面監視（3・4・6・7）中は、視点が頭の位置まで横に移る（調整画面でオン・オフ・追加の横移動・高さ）
- 乗車中は、どのポーズでも脚はまっすぐ
- 解除はスニークした時だけ（死亡・リスポーン・ディメンション移動・ログアウト時も解除）
- スニーク中・就寝中はポーズを取れない。MPMのモーション中にポーズを選ぶとMPMのモーションは自動で解除

## 使用権限（マルチプレイ）

- 初期設定ではOP（権限レベル不問）だけがポーズを使える。ただし **5 起立** は誰でも使える
- OPでない人の選択画面では使えないポーズが暗く表示され、↑↓では「解除」と「起立」の間だけを切り替える
- シングルプレイ（LAN公開時のホストを含む）では常に使える
- ポーズ中にOPを外されるとその場で解除（2秒以内に反映。起立はそのまま）
- サーバー稼働中に `/posemode op`（OPのみ）・`/posemode all`（全員）で切り替え。`/posemode` だけなら今の設定を表示
  - 使えるのは OP・シングルプレイのホスト・サーバーのコンソール
  - 切り替えると全員のチャットに知らせ、「OPのみ」にした時点でOPでない人のポーズは解除（起立はそのまま）
  - 設定はサーバーの `config/playerpose-server.cfg`（`opOnly`）に保存

## 調整画面

| 項目 | 内容 | 共有 |
|---|---|---|
| 横（傾く方向） | 側面監視（3・4・6・7）で乗車中に体をずらす量（初期値 3px） | 周りにも見える |
| 高さ | 側面監視と起立（5）で乗車中に体を上げる量（初期値 0.5ブロック） | 周りにも見える |
| 視点を頭に合わせる | 側面監視中、視点を頭の位置まで横に移す（初期値オン） | 自分の画面だけ |
| 視点の横移動（追加） | 頭の位置からさらに外側へ（0〜1.5ブロック） | 自分の画面だけ |
| 視点の高さ（追加） | 上下（−1〜+1ブロック）。起立中も乗車中だけ同じ値で上下する | 自分の画面だけ |
| 根元の位置（横・縦） | 手上げで持つアイテムの、手に持たせる点（右下のパネル） | 自分の画面だけ |
| 回す角度 | 手を中心にアイテムを回す（−180〜+180°、初期値 −40°） | 自分の画面だけ |

## 設定ファイル（config/playerpose.cfg）

書き換えて `/pose reload` で反映。

- `doorHold`（8 扉抑え（右手上げ））/ `sideWatch`（4 左側面監視）/ `sideWatchRaise`（3 左側面監視（手上げ））/ `raiseHand`（9 右手上げ）/ `stand`（5 起立）：各ポーズの角度。反対向きは自動で左右反転
  - 各部位は `"X,Y,Z"`（度）。X：マイナスで前へ / Z：右腕右脚はプラス、左腕左脚はマイナスで外側へ
  - `bodyLean`：上半身を腰から傾ける角度（プラスで左へ）
- `mirroredItemPoses`：アイテムを上げた手に持ち絵を反転するポーズ番号（初期値 `1,3,7,9`）
- `itemGripU` / `itemGripV`：手上げで持つアイテムの根元（手に持たせる点）の位置。テクスチャの左端・上端から何割か（調整画面でも変更可）
- `itemTiltDeg`：アイテムを手を中心に回す角度（初期値 `-40`。マイナスで外側＝腕の向きへ、プラスで内側へ）
- 0.9.2 までの `itemFlipPivotU` / `itemPivotV` は使わなくなったので自動で消える。`itemTiltDeg` が以前の初期値 `40` のままなら `-40` に置き換わる
- 以前の版の設定（`pose1` などの名前・古い番号）は自動で新しい名前・番号に引き継がれる

角度の設定は **その人の画面の描画にだけ** 効く。決まったら `PoseRegistry.java` の初期値に書き写して配布する。

## ダウンロード

[Releases](../../releases) ページから最新版の jar と README.txt を入手できます。

## ビルド

`main` ブランチに push すると GitHub Actions で自動ビルドされる。Actions の各実行ページの「Artifacts」に、配布用 jar と README.txt が入る。
`0.9.0` のようなバージョン番号のタグを push すると、そのバージョンでビルドして Releases に自動で公開する。

More Player Models はリポジトリに含めず、ビルド時に CurseForge（Curse Maven）から取得する。
