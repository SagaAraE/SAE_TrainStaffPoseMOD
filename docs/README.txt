==============================================================
  SAE TrainStaffPose
  バージョン : {VERSION}
  製作者     : SagaAraE
==============================================================

列車乗務員向けに、プレイヤーに静止ポーズを取らせるmodです。

--------------------------------------------------------------
■ 動作環境
--------------------------------------------------------------
・Minecraft Java Edition 1.7.10
・Minecraft Forge 10.13.4.1614
・前提mod：More Player Models 1.7.10b（このバージョン専用です）

--------------------------------------------------------------
■ 導入方法
--------------------------------------------------------------
同梱の playerpose-{VERSION}.jar を、サーバーと全クライアントの
両方の mods フォルダに入れてください。
（片方だけに入れると動きません。更新するときも両方を入れ替えてください）

--------------------------------------------------------------
■ 操作方法
--------------------------------------------------------------
【キー】（「設定 → 操作設定」で変更できます）
  Home   選択画面（円形メニュー）を開く
  ↑     次のポーズへ切り替え（円形メニューを時計回り）
  ↓     前のポーズへ切り替え（円形メニューを反時計回り）

  ↑を押すごとに、次の順番で切り替わります（↓はその逆）。
    解除 → 左手上げ → 左扉抑え → 左側面監視（手上げ） → 左側面監視 → 起立
    → 右側面監視 → 右側面監視（手上げ） → 右扉抑え → 右手上げ → 解除 …
  切り替えると、画面の上の方にポーズ名が表示されます。

【選択画面】
  ・扇形をクリック、または数字キー 1〜9 でポーズを取る
  ・下の「解除」、中央の円のクリック、または 0 キーで解除
  ・Esc / Home キー / 円の外のクリックで閉じる
  ・中央に、マウスを乗せたポーズのプレビューが表示されます
  ・「調整」ボタンで調整画面を開きます

  円形メニューの並び：
                    5 起立
      4 左側面監視              6 右側面監視
      3 左側面監視（手上げ）    7 右側面監視（手上げ）
      2 左扉抑え                8 右扉抑え
      1 左手上げ                9 右手上げ
                    0 解除

【コマンド】
  /pose          選択画面を開く
  /pose 1〜9     その番号のポーズを取る
  /pose off      ポーズを解除する（/pose 0 でも可）
  /pose reload   設定ファイルを読み直す（角度などを調整したとき）

--------------------------------------------------------------
■ ポーズ一覧
--------------------------------------------------------------
  0  解除
  1  左手上げ              （歩くと、下ろした腕と脚が動きます）
  2  左扉抑え
  3  左側面監視（手上げ）
  4  左側面監視
  5  起立                  （歩くと、腕と脚が動きます）
  6  右側面監視
  7  右側面監視（手上げ）
  8  右扉抑え
  9  右手上げ              （歩くと、下ろした腕と脚が動きます）

・手上げ（1・9）と側面監視（手上げ）（3・7）では、手に持ったアイテムを
  上げた手に持ち、絵を左右反転して外側へ倒して描きます。
・乗車中は、どのポーズでも脚はまっすぐになります。

--------------------------------------------------------------
■ ポーズの解除
--------------------------------------------------------------
・スニークすると解除されます（歩いたり乗り降りしたりしても解除されません）。
・死亡・リスポーン・ディメンション移動・ログアウトでも解除されます。
・スニーク中・就寝中はポーズを取れません。
・More Player Models のモーション中にポーズを選ぶと、
  そのモーションは自動で解除されます。

--------------------------------------------------------------
■ 使用権限（マルチプレイ）
--------------------------------------------------------------
・マルチプレイのサーバーでは、初期設定ではOP（権限レベルは問いません）だけが
  ポーズを使えます。OPでない人も、他の人のポーズは見えます。
・ただし「5 起立」だけは、OPでなくても誰でも使えます。
  （OPでない人の選択画面では、使えないポーズが暗く表示されます。
    ↑↓キーでは「解除」と「起立」の間だけを切り替えます）
・シングルプレイ（LAN公開した世界のホストを含む）では、常に使えます。
・ポーズ中にOPを外されると、その場でポーズが解除されます（起立はそのまま）。

【OPのみ／全員 の切り替え（サーバー稼働中に変更できます）】
  /posemode       今の設定を表示
  /posemode op    OPのみ使用可能にする
  /posemode all   全員使用可能にする

・このコマンドは、OP・シングルプレイのホスト・サーバーのコンソールが使えます。
・切り替えると、サーバーにいる全員のチャットに知らせが出ます。
・「OPのみ」に切り替えた時点で、OPでない人のポーズは解除されます（起立はそのまま）。
・設定はサーバーの config/playerpose-server.cfg に保存され、再起動後も引き継がれます。

--------------------------------------------------------------
■ 調整画面（選択画面の「調整」ボタン）
--------------------------------------------------------------
後ろからの視点に切り替わり、自分の姿を見ながら調整できます。

  横（傾く方向）       側面監視（3・4・6・7）で、乗車中に体を
                       傾く方向へずらす量
  高さ                 側面監視（3・4・6・7）と起立（5）で、
                       乗車中に体を上げる量
  視点を頭に合わせる   側面監視中、視点を傾けた頭の位置まで横に移す
  視点の横移動（追加） 視点を頭の位置からさらに外側へずらす量
  視点の高さ（追加）   視点を上下にずらす量（上がプラス）

・「横」と「高さ」は、周りの人にも同じ位置で見えます。
・「視点を頭に合わせる」「視点の横移動（追加）」「視点の高さ（追加）」は、
  自分の画面だけに効きます。
・調整した値は自動で保存されます。

--------------------------------------------------------------
■ 設定ファイル（config/playerpose.cfg）
--------------------------------------------------------------
書き換えたあと /pose reload で、再起動せずに反映できます。

  doorHold / sideWatch / sideWatchRaise / raiseHand / stand
      各ポーズの角度（"X,Y,Z" の度数）。
      doorHold = 2 左扉抑え、sideWatch = 4 左側面監視、
      sideWatchRaise = 3 左側面監視（手上げ）、raiseHand = 9 右手上げ、stand = 5 起立。
      反対向き（8・6・7・1）は左右反転で自動的に作られます。
  mirroredItemPoses   アイテムを上げた手に持ち、絵を反転するポーズ番号
  itemTiltDeg         アイテムを外側へ倒す角度（内側に倒れる場合はマイナスに）
  itemFlipPivotU / itemPivotV
                      アイテムの持ち手の位置（反転・回転の中心）

※ポーズの角度の設定は、その人の画面にだけ反映されます。
※以前の版の設定ファイルは、新しい番号と名前に自動で引き継がれます。
